# Student Grade Calculator

A beginner-friendly C++ console project that calculates a student's total marks, percentage, grade, and result status.

## Features

- Accepts marks for multiple subjects
- Validates marks between 0 and 100
- Calculates total marks and percentage
- Assigns grade based on percentage
- Displays pass or fail status

## Concepts Practiced

- Variables and data types
- Loops
- Conditional statements
- Functions
- Input validation

## Run Locally

```bash
g++ src/main.cpp -o grade-calculator
./grade-calculator
```

On Windows PowerShell:

```powershell
g++ src/main.cpp -o grade-calculator.exe
.\grade-calculator.exe
```
